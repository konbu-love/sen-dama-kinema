# 蛇玉キネマ

昭和初期の無声映画風・蛇玉鑑賞シミュレーター

線香花火が火花の散りゆく美しさを楽しむものなら、蛇玉は成長していく不思議な姿を楽しむもの。

地面に置いた蛇玉に火をつけると、黒い燃えカスがニョロニョロと伸びていきます。

その奇妙な成長を、昭和初期の無声映画のようなモノクロ画面で再現しました。

▶ **遊ぶ：https://konbu-love.github.io/sen-dama-kinema/**

## 遊び方

1. 「着火」ボタンを押します。
2. 蛇玉が少しずつ成長します。
3. 成長が終わったら、完成した姿をしばらく鑑賞します。
4. 最後に「完」の字幕が表示されます。
5. もう一度楽しみたい場合は、再挑戦できます。

## こだわり

- 完全モノクロの画面
- 昭和初期の無声映画を思わせる字幕
- フィルムの粒子、傷、明滅、画面の揺れ
- 黒く乾いた灰や炭を思わせる蛇玉の造形
- 成長後の姿を眺めるための余韻の時間

## 制作の裏話：AI三社競演

本来はChatGPTにCodexを使って実装してもらうつもりでした。

ところが、ChatGPTはこの会話の裏でCodexを起動して作業させることができず、スマートフォンからの利用もすんなり進みませんでした。

そこで登場したのがGoogle先生。

GitHubに公開できる単一HTMLのコードを生成してくれました。

実際に公開してみると、蛇玉の成長が終わった途端に画面が切り替わってしまいます。

「実際の蛇玉は、そんなにすぐ終わらないだろう！」

と指摘すると、Google先生は鑑賞時間を追加した修正版を出してくれました。

そしてChatGPTは、そのGoogle先生のコードを検品。

「ここが間違っています」「ここも修正が必要です」と指摘したあと、自分で清書した `index.html` をドヤ顔で納品しました。

( ｰ`дｰ´)ｷﾘｯ

……いや、最初からお前が作れ。

なお、GitHubへの公開手順はClaudeくんに案内してもらいました。

というわけで、

- **Google先生**：コード生成と修正
- **ChatGPT**：検品と清書（および反省）そしてREADMEの執筆
- **Claudeくん**：GitHub公開案内
- **人間**：企画、実物との照合、仕様の指摘

という、なんとも不思議な分業体制で完成しました。
